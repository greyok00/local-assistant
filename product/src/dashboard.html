Static folder or WordPress plugin; both use the two files from Build.

Static site

  1. Copy the assistant folder to your site, for example /assistant/.
  2. Upload the two index files from the Build tab into that same folder.
  3. Add this line before </body> on every page: 
    <script type="module" src="/assistant/loader.js"
  data-assistant data-config="/assistant/assistant.config.json"></script>
  4. Reload the site twice. The chat pill appears bottom-right.

The site must be served over HTTPS or localhost; browsers block the model on plain HTTP and from file://.

WordPress

  1. Upload the plugin zip in Plugins → Add New → Upload Plugin.
  2. Activate it, then open Settings → Local Assistant.
  3. Enter the site URL, press Build index, then Save to WordPress.
  4. The assistant appears on every public page; no theme edit needed.

The index is stored in wp-content/uploads/local-assistant/.

Does anything leave my server?

No. The page downloads the site's own HTML, builds vectors in this browser, and hands you two files. There is no account, no API key, and no third-party request.

How often should I rebuild?

Only when the content changes. The index is a snapshot: new or edited pages stay invisible to the assistant until you rebuild and replace the two files.

Where do the two files go?

Beside the assistant's config, as assistant-index.json and assistant-index.bin. In WordPress, press Save to WordPress instead, the plugin stores them for you.

The report shows 127.0.0.1 links. Is that wrong?

Yes, for a live site. Ingesting through a local server records local addresses. Ingest the public URL instead, or rewrite those URLs to site-relative paths before uploading.

Will it work on phones and other browsers?

Yes. It appears on phones, tablets, and every current browser, with nothing for the visitor to set up.

Do the colors need configuring?

No. The widget samples the host page's background, text, and accent token, then derives its own surfaces with contrast correction. The accent setting is used only when the theme exposes no color.

It says it could not read the site.

That is usually cross-origin access: a server that does not send CORS headers. Ingest the site's own address, from a page on that same domain, or add Access-Control-Allow-Origin for this page.

How large will the index be?

Roughly 1.5 KB of vectors per chunk and a little more in metadata, so a few hundred pages usually lands between 2 and 6 MB in total.

Runs entirely in the browser. Nothing is uploaded. No account, no API key.
